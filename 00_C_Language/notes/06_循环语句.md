# 1. while 语句

## 1.1 迭代与 while 循环的引入

- **迭代（Iteration）**：每次执行都在重复同类操作，但每次的状态略有区别（例如循环变量的值不同）。计算机最擅长执行成千上万次的重复操作，且能保证准确性。
- **循环的意义**：递归可以实现迭代逻辑，但C语言提供了专门的循环语句（如`while`），让迭代程序的编写更直观、更符合命令式编程的思维。

### 1.1.1 阶乘的循环实现示例

```c
int factorial(int n)
{
    int result = 1;
    while (n > 0) {
        result = result * n;
        n = n - 1;
    }
    return result;
}
```

## 1.2 while 语句的基本语法与执行机制

- **语法结构**：`语句 → while (控制表达式) 语句`
- **组成**：由控制表达式和子语句（循环体，通常是由多条语句组成的语句块）两部分构成。
- **执行流程**：
  1. 计算并测试控制表达式的值。
  2. 若值为**真（非0）**，执行循环体语句，执行完成后再次测试控制表达式。
  3. 若值为**假（0）**，跳出循环，继续执行循环之后的代码。
  4. **注意**：如果第一次测试控制表达式就为假，循环体**一次都不会执行**。

## 1.3 循环中的核心变量

1. **累加器（Accumulator）**：在循环中累积每一步的中间结果
   - 乘法累积场景，初值通常设为 `1`（如阶乘示例中的 `result = 1`）。
   - 加法累积场景，初值通常设为 `0`。
2. **循环变量（Loop Variable）**：每次循环都会更新它的值，并在控制表达式中被判断，二者共同控制循环的执行次数
   - 可以是递减形式（如 `n = n - 1`），也可以是递增形式。

## 1.4 递归与循环（迭代）的对比

- **思维方式不同**：
  - 递归依靠**递推关系**（如 (n! = n \times (n-1)!)），从目标向终止条件拆解。
  - 循环更像把公式**展开执行**（如 (n! = n \times (n-1) \times ... \times 1)），从初始值向结果推进。
- **可读性**：当公式本身是展开形式时，循环更直观；当问题的递推关系清晰、结构复杂时，递归表达更简洁。
- **底层机制**：递归会频繁分配、释放栈帧变量；循环则通过对同一变量多次赋值来完成迭代。
- **编程范式**：
  - **函数式编程（Functional Programming）**：递归是典型代表，类似数学函数，强调无副作用，代表语言如 Lisp、Haskell。
  - **命令式编程（Imperative Programming）**：循环是典型代表，也是C语言的主流模式。多次对同一变量赋值容易引入Bug，**推荐做法：对同一变量保持一致的修改逻辑，尽量减少无意义的多次赋值**。

## 1.5 死循环（Infinite Loop）与边界条件

- **死循环成因**：如果`while`的控制表达式恒为真（如 `while (1) {...}`），或者忘记更新循环变量（如漏写 `n = n - 1`），就会形成死循环。
- **判断死循环并不总是直观**：例如著名的 **(3x+1) 问题（Collatz 猜想）**：
```c
while (n != 1) {
    if (n % 2 == 0) n = n / 2;
    else n = n * 3 + 1;
}
```

目前验证过的所有正整数，最终都能变为1从而跳出循环，但**至今无人能从数学上证明**它对所有正整数都不会成为死循环。编写循环时，应有意识地检查控制表达式和循环变量更新逻辑的正确性。

## 1.6 习题解答与思路

### 习题 1：用循环实现递归章节的所有习题，体会两种思路的差异

1. **欧几里得算法（GCD）的循环实现**

```c
int gcd(int a, int b) {
    a = abs(a); b = abs(b);
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}
```
2. **Fibonacci 数列的循环实现**（避免了递归的重复计算问题）

```c
int fib(int n) {
    if (n == 0 || n == 1) return 1;
    int a = 1, b = 1, result = 1;
    for (int i = 2; i <= n; i++) { // 此处用 for 循环更清晰，while 也可实现
        result = a + b;
        a = b;
        b = result;
    }
    return result;
}
```

### 习题 2：统计 1 到 100 的所有整数中，数字 9 出现的总次数

- **思路拆解**：
  1. **循环变量**：`i`，从 1 递增遍历到 100。
  2. **累加器**：`count`，统计出现次数，初值为 0，做加法累积。
  3. **数位提取**：个位为 `i % 10`，十位为 `i / 10`；注意 99 会贡献两个 9，需要分别计数。
- **代码实现**：
```c
#include <stdio.h>
int main(void) {
    int count = 0; // 累加器
    for (int i = 1; i <= 100; i++) { // 循环变量
        if (i % 10 == 9) {
            count++; // 个位是 9
        }
        if (i / 10 == 9) {
            count++; // 十位是 9
        }
    }
    printf("1到100中数字9出现的次数为: %d\n", count); // 结果为 20 次
    return 0;
}
```

# 2. do/while 语句

## 2.1 语法与执行机制
- **语法格式**：`语句 → do 语句 while (控制表达式);`
- **执行流程**：**先执行循环体（`do` 后面的语句），再计算并测试控制表达式的值**。
- **核心特点**：无论控制表达式的初始值是真还是假，**循环体至少会被执行一次**。测试结果为真则继续循环，为假则退出循环。

## 2.2 与 while 语句的对比
- **`while` 语句**：先测试控制表达式的值，再决定是否执行循环体。如果初始条件就为假，循环体一次都不会执行。
- **`do/while` 语句**：先执行一次循环体，再测试条件。适合“逻辑上至少需要执行一次”的场景。
- **等价性说明**：从功能上讲，只用 `while` 循环就可以覆盖所有循环场景，`do/while` 和 `for` 循环都可以改写为 `while` 循环。但在特定场景下，使用 `do/while` 或 `for` 代码更简洁、可读性更好。

## 2.3 代码示例：do/while 实现阶乘
使用 `do/while` 循环计算阶乘：
```c
int factorial(int n)
{
    int result = 1;
    int i = 1;
    do {
        result = result * i;
        i = i + 1;
    } while (i <= n);
    
    return result;
}
```

## 2.4 编写循环的注意事项
- **准确处理临界条件**：编写循环时必须注意循环结束的临界条件是否准确。  
      **反例说明**：上面的阶乘示例中，如果循环结束条件写成 `i < n` 就是错误的。当 `i == n` 时就会跳出循环，导致结果中少乘了 `n`，正确写法应为 `i <= n`。  
- **循环变量命名习惯**：变量名应当尽量有语义，但在循环场景中，使用 `i`、`j`、`k` 作为循环变量名是行业通用的惯例。

# 3. for 语句

## 3.1 基本语法与等价转换
- **语法格式**：`for (控制表达式1; 控制表达式2; 控制表达式3) 语句`
- **等价于 while 循环**（不考虑循环体中 `continue` 语句的场景下）：
  ```c
  控制表达式1;
  while (控制表达式2) {
      语句;
      控制表达式3;
  }
  ```
- **阶乘实现示例**：
  ```c
  int factorial(int n)
  {
      int result = 1;
      int i;
      for (i = 1; i <= n; ++i)
          result = result * i;
      return result;
  }
  ```

## 3.2 控制表达式的省略规则
- **表达式1和表达式3可以为空**：例如 `for (; i <= n;)` 是合法语法。
- **表达式2的特殊规则**：C语言规定，如果控制表达式2为空，则默认其值为真。
- **死循环写法**：`for (;;) {...}` 等价于 `while (1) {...}`，均表示无限循环。

## 3.3 自增与自减运算符（++, --）
### 前缀形式 (Prefix)
- 写法：`++i`（自增）、`--i`（自减）
- 等价逻辑：`i = i + 1` 或 `i = i - 1`
- **返回值**：返回**加/减1之后**的变量值

### 后缀形式 (Postfix)
- 写法：`i++`（自增）、`i--`（自减）
- **返回值**：返回**加/减1之前**的变量原值

### 共性与编码规范
- **共同点**：都会产生**副作用（Side Effect）**，即修改变量本身的存储值。
- **代码规范建议**：经典 K&R 风格常组合使用 `++`/`--` 压缩代码，但会降低可读性。初学者建议将 `++`、`--` 单独作为一条语句使用，不要嵌套在其他复杂表达式中。

## 3.4 复杂表达式解析（如 `a+++b`）
- **编译的两个阶段**：分为**词法分析（Lexical Analysis）**和**语法分析（Syntax Analysis）**。
- **词法分析规则**：编译器从前到后扫描时，遵循**最长匹配原则**，总是取最长的合法 Token。因此 `a+++b` 会被解析为 `a++`、`+`、`b`，即等价于 `(a++) + b`。
- **语法分析约束**：
  - `a` 是左值表达式，`a++` 的结果是右值表达式。
  - `a++ + b` 是合法表达式；但 `a++++` 会编译报错，因为后缀 `++` 返回的是右值，不能作为下一个 `++` 的操作数（自增运算符要求操作数是可修改的左值）。

## 3.5 C99 标准的 for 内变量定义
- **新特性**：C99 标准允许在 `for` 循环的控制表达式1中直接定义变量：
  ```c
  for (int i = 1; i <= n; i++) {
      // ...
  }
  ```
- **作用域**：这种方式定义的 `i` 属于语句块级局部变量，**仅在 for 循环内部有效**，循环结束后无法访问。
- **编译与兼容性**：使用 gcc 编译该语法需要添加 `-std=c99` 选项。该特性借鉴自 C++，考虑到跨编译器兼容性，不建议初学者普遍使用。

# 4. break 和 continue 语句

## 4.1 核心概念对比

- **`break` 语句**：用于**跳出整个循环体**（在 `switch` 语句中也用于跳出 `switch` 代码块）。一旦执行，当前循环彻底终止。
- **`continue` 语句**：**终止当前这一轮循环**，跳过循环体中后续的代码，直接回到循环开头，准备执行下一轮循环。
  - 对于 `while` 和 `do/while` 循环：执行 `continue` 后，立即跳转去测试控制表达式。
  - 对于 `for` 循环：执行 `continue` 后，先执行控制表达式3（例如 `i++`），再去测试控制表达式2。

## 4.2 代码示例：求 1-100 的素数

### 4.2.1 `is_prime` 函数解析

```c
int is_prime(int n)
{
    int i;
    for (i = 2; i < n; i++)
        if (n % i == 0)
            break; // 发现能整除，立刻跳出循环，不再执行 i++
    if (i == n)
        return 1;
    else
        return 0;
}
```

- **逻辑说明**：从 2 到 n-1 依次检查是否能整除 n。
- **`break` 的作用**：一旦发现能整除的因子（说明不是素数），立即终止循环。
- **结果判断逻辑**：
  - 如果 n 不是素数，循环被 `break` 提前打断，循环结束后 `i` 一定**小于** `n`。
  - 如果 n 是素数，循环会完整执行完毕，结束后 `i` 一定**等于** `n`。
- ?? **临界条件说明**：当 `n=2` 时，循环条件 `2 < 2` 不成立，循环一次都不执行，`i` 的初始值就是 2。因此结束后 `i == n`，可以正确判定 2 是素数。
- ? **优化思路**：实际上不需要从 2 一直检查到 n-1，只需要检查到 (\sqrt{n}) 即可。如果小于等于 (\sqrt{n}) 的数都不能整除 n，那么大于 (\sqrt{n}) 的数也必然不能整除 n。

### 4.2.2 `main` 函数解析

```c
int main(void)
{
    int i;
    for (i = 1; i <= 100; i++) {
        if (!is_prime(i))
            continue; // 如果不是素数，跳过本次循环，直接执行 i++
        printf("%d\n", i); // 只有素数才会执行到这行
    }
    return 0;
}
```

- **`continue` 的作用**：当 `i` 不是素数时，跳过后续的 `printf` 语句，直接进入下一轮循环（执行 `i++`）。
- **作用域提示**：主函数中的局部变量 `i` 和 `is_prime` 函数中的局部变量 `i` 是**完全独立的两个变量**。调用函数时，只是将实参的值传递给了形参。

## 4.3 习题解答

**习题 1**：求素数的程序只是为了演示 `break` 和 `continue` 的用法才这样编写。实际上完全可以不用 `break` 和 `continue`，请修改控制流程，去掉 `break` 和 `continue` 并保持功能不变。

### 解答代码：

```c
#include <stdio.h>
int is_prime(int n)
{
    int i;
    // 直接用 return 替代 break 提前结束函数
    for (i = 2; i < n; i++) {
        if (n % i == 0)
            return 0; // 只要发现能整除，直接返回0（非素数）
    }
    return 1; // 循环完整结束未返回0，说明是素数
}
int main(void)
{
    int i;
    for (i = 1; i <= 100; i++) {
        // 用 if 反向条件判断替代 continue
        if (is_prime(i)) {
            printf("%d\n", i);
        }
    }
    return 0;
}
```

> 
> 另一种不改动 return 逻辑的写法是引入标志位 `flag`，但直接使用 `return` 写法更简洁。

**习题 2**：上一节讲过可以把 `for` 循环改写成等价的 `while` 循环，但也提到如果循环体中有 `continue` 语句，两种形式就不再等价。思考一下为什么不等价？

### 解答：

因为 `continue` 会跳过循环体中剩余的语句，直接执行下一轮循环的准备动作，而两种循环中 `continue` 跳转后的执行逻辑不同：

- 在 **`for` 循环**中，`continue` 会**先执行控制表达式3（如 `i++`）**，再测试控制表达式2，符合正常的迭代逻辑。
- 在 **`while` 循环**中，如果手动将 `for (i=1; i<=n; i++)` 改写为 `i=1; while(i<=n) { ...; i++; }` 的形式，一旦循环体内执行 `continue`，程序会**直接跳回 `while (i<=n)` 进行条件测试**，从而**跳过了末尾的 `i++` 语句**。

这会导致：如果 `while` 的条件始终为真，且循环体内触发 `continue`，变量 `i` 将无法自增，最终形成**死循环**。因此当循环体中存在 `continue` 时，`for` 和 `while` 的简单等价关系不成立。

# 5. 嵌套循环

## 5.1 嵌套循环的概念与注意事项

- **概念**：在一个循环的循环体内部，又包含另一个完整的循环结构，称为嵌套循环。上一节中在循环内调用包含循环的函数，本质上也属于嵌套循环。
- **变量命名规范**：内层循环的循环变量不能与外层重名。行业惯例是外层用 `i`，内层用 `j`，多层嵌套可依次使用 `k` 等。
- **跳转语句的作用域限制**：
  - 多层循环或 `switch` 嵌套的场景下，`break` 语句**只能跳出最内层**的循环或 `switch` 结构。
  - `continue` 语句也**只能结束最内层**循环的当前迭代，回到该内层循环的开头。

## 5.2 示例 1：用嵌套循环求 1-100 的素数

将之前调用函数的逻辑直接展开，使用双重 `for` 循环实现素数判断：

```c
#include <stdio.h>
int main(void)
{
    int i, j;
    for (i = 1; i <= 100; i++) {       // 外层循环：遍历1到100的所有整数
        for (j = 2; j < i; j++) {      // 内层循环：检查2到i-1是否存在i的因子
            if (i % j == 0)
                break;                 // 发现能整除，说明非素数，跳出内层循环
        }
        if (j == i)                    // 内层循环完整结束（未被break打断），说明是素数
            printf("%d\n", i);
    }
    return 0;
}
```

## 5.3 示例 2：打印九九乘法表

通过嵌套循环打印格式化的二维表格数据：

```c
#include <stdio.h>
int main(void)
{
    int i, j;
    for (i = 1; i <= 9; i++) {         // 外层循环控制行数
        for (j = 1; j <= 9; j++) {     // 内层循环控制列数
            printf("%d\t", i * j);     // \t 为制表符，用于实现列对齐
        }
        printf("\n");                  // 每打印完一行，执行换行
    }
    return 0;
}
```

> 
> 注：原示例使用空格 `"%d  "` 会导致一位数和两位数混排时错位，改用制表符 `"%d\t"` 可实现自动对齐。

## 5.4 习题解答

### 习题 1：修改程序打印“不重复”的小九九（仅打印下三角）

- **需求**：由于 (8 \times 9) 和 (9 \times 8) 结果相同，完整九九表有一半数据重复。要求打印阶梯状的下三角格式。
- **核心修改思路**：只需修改内层循环的终止条件，让列号 `j` 不超过当前行号 `i` 即可。
- **代码实现**：
```c
#include <stdio.h>
int main(void)
{
    int i, j;
    for (i = 1; i <= 9; i++) {
        for (j = 1; j <= i; j++) { // 核心修改：j 最大只遍历到 i
            printf("%d\t", i * j);
        }
        printf("\n");
    }
    return 0;
}
```

### 习题 2：编写函数 `diamond(int n, char c)` 打印菱形

- **需求说明**：
  1. 调用 `diamond(3, '*')` 和 `diamond(5, '+')` 可打印对应大小的菱形。
  2. 若参数 `n` 为偶数，打印错误提示。
- **实现分析**：
  - 菱形可拆分为**上半部分（包含中间最长行）**和**下半部分**。
  - 上半部分行数为 `(n + 1) / 2`，下半部分行数为 `n / 2`。
  - 空格规律：每行开头的空格数随行数递增而递减，下半部分反之。
  - 字符规律：每行字符数为 `2 * 行号 - 1`（上半部），下半部依次递减。
- **代码实现**：
```c
#include <stdio.h>
void diamond(int n, char c)
{
    // 1. 偶数参数校验，打印错误提示并返回
    if (n % 2 == 0) {
        printf("Error: n must be an odd number.\n");
        return;
    }
    int i, j;
    int half = n / 2;
    // 2. 打印上半部分（包含中间最长行）
    for (i = 1; i <= half + 1; i++) {
        // 打印前置空格
        for (j = 1; j <= half + 1 - i; j++) {
            printf(" ");
        }
        // 打印菱形字符
        for (j = 1; j <= 2 * i - 1; j++) {
            printf("%c", c);
        }
        printf("\n");
    }
    // 3. 打印下半部分
    for (i = half; i >= 1; i--) {
        // 打印前置空格
        for (j = 1; j <= half + 1 - i; j++) {
            printf(" ");
        }
        // 打印菱形字符
        for (j = 1; j <= 2 * i - 1; j++) {
            printf("%c", c);
        }
        printf("\n");
    }
}

int main(void)
{
    diamond(3, '*');
    printf("\n");
    diamond(5, '+');
    printf("\n");
    diamond(4, '#'); // 测试偶数参数报错
    return 0;
}
```

# 6. goto 语句和标号

## 6.1 goto 语句与标号的基本概念
- **作用**：`goto` 语句实现**无条件跳转**，可以从程序中的一处直接跳转到另一处执行。
- **标号（Label）**：跳转的目标位置。任何语句前面都可以添加标号，标号命名遵循标识符的命名规则，格式为 `标号名:`。
- **典型使用场景**：从多层嵌套循环中直接跳出所有循环，执行统一的错误处理逻辑。
  ```c
  for (...) {
      for (...) {
          ...
          if (出现错误条件)
              goto error; // 直接跳出所有层级的循环
      }
  }
  error:
      出错处理代码;
  ```

## 6.2 核心限制与缺点
- **作用域限制**：`goto` 只能跳转到**同一个函数内部**的标号处，**不能跨函数跳转**。
- **主要缺点**：`goto` 的能力过于灵活，滥用会让程序的控制流变得混乱，**严重降低代码的可读性和可维护性**。著名计算机科学家 Dijkstra 曾提出“goto 语句有害论”，提倡在高级语言中限制使用 goto。

## 6.3 替代方案：布尔标志位
如果不使用 `goto`，可以引入一个布尔标志位（标志变量），配合逐层 `break` 实现多层循环跳出：
```c
int cond = 0; /* 标志变量，标记是否出现错误 */
for (...) {
    for (...) {
        ...
        if (出现错误条件) {
            cond = 1;
            break; // 跳出内层循环
        }
    }
    if (cond)
        break; // 跳出外层循环
}
if (cond)
    出错处理代码;
```

> 注：现代语言如 C++、Java 等引入了异常处理机制（Exception），可以完全替代这种用于错误处理的 `goto` 用法。

## 6.4 合理使用 goto 的唯一场景
当函数中多处可能触发错误时，可以统一跳转到函数末尾执行统一的收尾处理（例如释放先前分配的资源、恢复被修改的全局变量等），处理完成后函数返回。这种场景下使用 `goto` 反而能让代码更简洁、结构更清晰，避免重复编写收尾代码。

## 6.5 语法扩展：标号与 switch 的本质
- **`case` 和 `default` 本质上也是标号**：在 `switch` 语句中，`case 常量表达式:` 和 `default:` 后的冒号语法，本质上就是两种特殊形式的标号。
- **语句块的本质**：从语法定义上看，`switch` 的语句块和其他分支、循环结构的语句块没有本质区别。
  ```
  语句 → 标号 语句
  语句 → case 常量表达式: 语句
  语句 → default: 语句
  语句 → { 语句列表 }
  ```
- **趣味拓展**：著名的 C 语言奇技淫巧 **Duff's Device**，正是利用了“`switch` 语句块和循环结构的语句块没有本质区别”这一语法特性，实现了一种巧妙的循环展开优化。
