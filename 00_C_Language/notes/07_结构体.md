# 1. 复合类型与结构体

## 1.1 复合类型与数据抽象

- **基本类型（Primitive Type）**：不可再拆分的基础数据类型，例如整型、浮点型。
- **复合类型（Compound Type）**：按照语法规则由基本类型组合而成的类型，例如字符串由多个字符组成。
- **数据抽象（Data Abstraction）**：复合类型既可以作为整体使用，也可以拆解为基本类型操作，这一特性奠定了数据抽象的基础。

**SICP 提出的学习编程语言的三个核心维度**：

1. 提供了哪些**原语**（基本类型、基本运算符、表达式和语句）。
2. 提供了哪些**组合规则**（基本类型如何组成复合类型，表达式如何组成复杂语句）。
3. 提供了哪些**抽象机制**（数据抽象和过程抽象）。

## 1.2 结构体的定义与声明

### 1.2.1 基本语法与 Tag

- **定义结构体**：用实部和虚部表示复数，可以定义为由两个 `double` 成员组成的结构体：
```c
struct complex_struct {
    double x, y;
};
```
- **Tag（标签）**：`complex_struct` 是标识符，在 C 语言中称为结构体的 Tag，命名遵循标识符命名规则。
- **类型名**：`struct complex_struct { double x, y; }` 整体可以看作一个完整的类型名，地位等同于 `int` 或 `double`。
- **定义结构体变量**：
  - 方式一：定义类型的同时声明变量
  ```c
  struct complex_struct { double x, y; } z1, z2;
  ```
  - 方式二：先定义类型，再通过 Tag 声明变量
  ```c
  struct complex_struct z3, z4;
  ```

### 1.2.2 匿名结构体与分号规则

- **分号强制要求**：结构体类型定义的右花括号 `}` 后面**必须加分号 `;`**，这是初学者高频易错点。
- **匿名结构体**：如果定义结构体类型的同时直接定义变量，可以省略 Tag。
```c
struct {
    double x, y;
} z1, z2; // 后续无法再用该类型定义其他变量
```

## 1.3 结构体成员的访问

### 1.3.1 点运算符与命名空间

- **成员（Member）**：结构体内部的变量，例如上例中的 `x` 和 `y`。
- **访问方式**：使用点运算符 `.`（Period）访问成员，例如 `z.x`、`z.y`。
- **内存布局**：结构体的多个成员存储空间连续排列，共同组成整个结构体变量的内存空间。
- **命名空间独立**：结构体成员 `x` 和外部普通变量 `x` 不会重名冲突。成员只能通过 `结构体变量.成员名` 的形式访问，编译器可以从语法上区分二者，它们属于不同的命名空间。

### 1.3.2 代码示例

```c
#include <stdio.h>
int main(void)
{
    struct complex_struct { double x, y; } z;
    double x = 3.0;
    z.x = x;   // 将外部变量 x 赋值给结构体成员 z.x
    z.y = 4.0;
    if (z.y < 0)
        printf("z=%f%fi\n", z.x, z.y);
    else
        printf("z=%f+%fi\n", z.x, z.y);
    return 0;
}
```

## 1.4 结构体的初始化

### 1.4.1 常规初始化

- 基本格式：`struct complex_struct z = { 3.0, 4.0 };`
- **初始化规则**：
  - 按照成员定义的顺序依次赋值。
  - 初始值数量多于成员数：编译器报错（尾部多余的逗号除外）。
  - 初始值数量少于成员数：未指定的成员默认用 `0` 初始化（规则类似全局变量）。
- **示例**：
```c
double x = 3.0;
struct complex_struct z1 = { x, 4.0 }; /* 局部变量可用变量初始化（C99特性） */
struct complex_struct z2 = { 3.0, };   /* z2.x=3.0, z2.y=0.0 */
struct complex_struct z3 = { 0 };      /* z3.x=0.0, z3.y=0.0 */
```

注：使用变量初始化结构体成员是 C99 新特性，C89 标准只允许使用常量表达式初始化。

### 1.4.2 错误的赋值语法

不能使用 `{}` 包裹的初始化列表对结构体进行赋值操作：

```c
struct complex_struct z1;
z1 = { 3.0, 4.0 }; // 错误！初始化列表不是可赋值的表达式
```

### 1.4.3 Designated Initializer (C99 新特性)

用于初始化稀疏结构体或数组，只对指定成员进行初始化，其余成员自动补 0。

- 格式：`.成员名 = 值
```c
struct complex_struct z1 = { .y = 4.0 }; /* z1.x=0.0, z1.y=4.0 */
```

## 1.5 结构体的运算限制与赋值

- **运算限制**：结构体类型不能使用算术运算符（`+ - * /`）和逻辑运算符（`&& || !`），也不能作为 `if`/`while` 的控制表达式。只有算术类型（标量类型）才具备这些运算特性。
- **合法赋值**：允许使用赋值运算符 `=` 拷贝整个结构体。
```c
struct complex_struct z1 = { 3.0, 4.0 };
struct complex_struct z2 = z1; // 合法：用 z1 初始化 z2
z1 = z2;                       // 合法：结构体之间整体赋值
```

## 1.6 结构体的传参与返回

结构体变量可以作为函数的参数和返回值传递：

```c
struct complex_struct add_complex(struct complex_struct z1, struct complex_struct z2)
{
    z1.x = z1.x + z2.x;
    z1.y = z1.y + z2.y;
    return z1;
}
```

- **按值传递（Call by Value）**：
  - 调用时，实参的值会被完整拷贝给形参 `z1` 和 `z2`（存储在 `add_complex` 的栈帧上）。
  - 函数内部对形参的修改，不会影响外部的实参变量。
- **返回值机制**：
  - 函数的返回值相当于一个**临时变量**，用 `return` 后的表达式进行初始化。
  - 函数返回、栈帧释放后，临时变量的值再赋值给调用方的接收变量。
- **左值特性说明**：
  - 成员表达式 `z.x` 可以做左值（因为 `z` 是变量，代表明确的存储位置）。
  - 函数调用 `add_complex(z, z).x` **不能做左值**，因为函数返回值是临时变量（右值），没有固定的存储位置。

  # 2. 数据抽象

## 2.1 复数运算程序的模块化设计

在上一节中，我们定义了复数的结构体。复数的表示有两种方式：

- **直角坐标 (x, y)**：做加减法比较方便。
- **极坐标 (r, A)**：做乘除法比较方便。

为了实现完整的复数运算程序，需要提供两层函数：

1. **存取层（底层表示）**
   - 获取实部 `real_part`，获取虚部 `img_part`
   - 获取模 `magnitude`，获取幅角 `angle`
   - 构造函数：从直角坐标构造 `make_from_real_img`，从极坐标构造 `make_from_mag_ang`
2. **运算层（高层操作）**
   - 加减法：利用实部和虚部进行运算，再通过 `make_from_real_img` 构造新复数
   - 乘除法：利用模和幅角进行运算，再通过 `make_from_mag_ang` 构造新复数

## 2.2 数据抽象的核心威力

**关键现象**：如果把底层的结构体定义从直角坐标 (`double x, y;`) 改为极坐标 (`double r, A;`)，只要保持底层存取函数（如 `real_part` 等）的函数名和返回值不变（仅修改内部实现），**高层的加减乘除运算函数（`add_complex` 等）一行代码都不需要修改**。

**原因**：加减乘除运算函数**不直接访问**结构体的成员变量（如 `z.x`），而是把复数当作一个整体，通过调用 `real_part(z)` 等**接口**来获取数据。

## 2.3 什么是抽象层 (Abstraction Layer)

这是一种抽象的设计思想，类似于提取公因式，通过分层隔离实现与细节：

- **运算层**：不需要知道复数底层到底是 `x,y` 还是 `r,A`，只知道复数有实部、虚部、模和幅角。
- **存储表示层**：专门负责处理底层的数据结构（直角坐标或极坐标），并向上提供统一的存取接口。
- **应用层**（更上层）：只需要知道复数可以加减乘除，甚至不需要知道它的底层构造。

**分层带来的好处**：

1. **隔离变化**：任何一层内部实现的改变，只要接口不变，就不会影响其他层。
2. **控制复杂度**：大问题被分解为小问题，通过组合简单的层来构建复杂的系统。

> 
> 名言：计算机科学家 Butler Lampson 曾说：“All problems in computer science can be solved by another level of indirection.”（计算机科学中的所有问题都可以通过增加一个间接层来解决），这里的 indirection 就是抽象的意思。

## 2.4 习题解答

### 习题 1：打印复数的函数

**题目要求**：实现一个打印复数的函数，格式为 `x+yi`。如果实部或虚部为0则省略。例如：`1.0`、`-2.0i`、`-1.0+2.0i`、`1.0-2.0i`。

**思考**：这个函数应该属于数据抽象分层中的哪一层？

**解答**：
这个函数属于**最上层（应用层）**。因为它只负责数据的格式化输出，不参与任何底层数据的存取，也不参与运算逻辑。它只需要调用底层的 `real_part` 和 `img_part` 接口来获取数据即可。

**代码实现**：

```c
#include <stdio.h>
#include <math.h>

void print_complex(struct complex_struct z)
{
    double re = real_part(z);
    double im = img_part(z);

    // 处理实部和虚部都为0的情况
    if (re == 0.0 && im == 0.0) {
        printf("0\n");
        return;
    }

    // 打印实部（如果非零）
    if (re != 0.0) {
        printf("%f", re);
    }

    // 打印虚部（如果非零）
    if (im != 0.0) {
        if (re != 0.0 && im > 0) {
            printf("+"); // 实部虚部都存在，且虚部为正，补充加号
        }
        // 处理虚部为 1 或 -1 的情况，省略系数 1
        if (im == 1.0) {
            printf("i");
        } else if (im == -1.0) {
            printf("-i");
        } else {
            printf("%fi", im); // 正常打印虚部
        }
    }
    printf("\n");
}
```

### 习题 2：有理数结构体及运算

**题目要求**：实现 `rational` 结构体及其相关的加减乘除函数，结果需约分为最简分数。

**解答思路与代码**：

```c
#include <stdio.h>
#include <stdlib.h> // 用于 abs()

// 1. 定义有理数结构体
struct rational {
    int num; // 分子 (numerator)
    int den; // 分母 (denominator)
};

// 辅助函数：求最大公约数（欧几里得算法）
int gcd(int a, int b) {
    a = abs(a);
    b = abs(b);
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}

// 构造函数：负责初始化和约分化简
struct rational make_rational(int num, int den) {
    struct rational r;
    // 处理分母为负的情况，统一将负号移到分子上
    if (den < 0) {
        num = -num;
        den = -den;
    }
    // 约分为最简分数
    int common = gcd(num, den);
    r.num = num / common;
    r.den = den / common;
    return r;
}

// 存取接口（为了抽象层设计，不直接访问成员）
int rat_num(struct rational r) { return r.num; }
int rat_den(struct rational r) { return r.den; }

// 运算层：加减乘除
struct rational add_rational(struct rational a, struct rational b) {
    return make_rational(
        rat_num(a) * rat_den(b) + rat_num(b) * rat_den(a),
        rat_den(a) * rat_den(b)
    );
}

struct rational sub_rational(struct rational a, struct rational b) {
    return make_rational(
        rat_num(a) * rat_den(b) - rat_num(b) * rat_den(a),
        rat_den(a) * rat_den(b)
    );
}

struct rational mul_rational(struct rational a, struct rational b) {
    return make_rational(
        rat_num(a) * rat_num(b),
        rat_den(a) * rat_den(b)
    );
}

struct rational div_rational(struct rational a, struct rational b) {
    return make_rational(
        rat_num(a) * rat_den(b),
        rat_den(a) * rat_num(b)
    );
}

// 打印函数（应用层）
void print_rational(struct rational r) {
    // 分母为1时直接打印分子
    if (rat_den(r) == 1) {
        printf("%d\n", rat_num(r));
    } else {
        printf("%d/%d\n", rat_num(r), rat_den(r));
    }
}
```

# 3. 数据类型标志

## 3.1 引入标志的目的

- **背景问题**：复数在计算机中可以用直角坐标存储，也可以用极坐标存储，两种格式互相转换会带来浮点数精度损失。
- **解决方案**：引入**数据类型标志（Tag）**。让 `complex_struct` 结构体由「一个标志位」和「两个浮点数」组成：
  - 标志为 `0`（RECTANGULAR）时，两个浮点数表示直角坐标 (x, y)
  - 标志为 `1`（POLAR）时，两个浮点数表示极坐标 (r, A)
- **核心好处**：直角坐标和极坐标的数据都可以直接存入结构体，**无需提前转换，无精度损失**。

## 3.2 枚举类型（enum）

### 3.2.1 基本语法

使用 `enum` 关键字定义枚举类型，用法类似结构体的 Tag。

```c
enum coordinate_type { RECTANGULAR, POLAR };
struct complex_struct {
    enum coordinate_type t;
    double a, b;
};
```

### 3.2.2 枚举的赋值规则

- **默认自动分配**：枚举成员是**整型常量**，默认从 `0` 开始依次递增。上例中 `RECTANGULAR` 为 0，`POLAR` 为 1。
- **显式指定值**：如果不希望从 0 开始，可以手动指定初始值，后续成员自动递增。
```c
enum coordinate_type { RECTANGULAR = 1, POLAR }; // RECTANGULAR为1，POLAR自动变为2
```
- **编译期常量**：枚举常量的值在编译阶段就已确定，可以用于初始化全局变量，也可以作为 `switch` 语句的 `case` 分支判断条件。

## 3.3 ?? 命名冲突（重点易错点）

- **结构体成员 vs 普通变量**：二者不在同一命名空间，**不会冲突**。例如结构体里定义 `int x`，外部也定义 `int x` 是合法的。
- **枚举成员 vs 普通变量**：C语言的枚举成员和普通变量在**同一个命名空间**，**会产生命名冲突**！
  - **错误示例**：
  ```c
  int main(void)
  {
      enum coordinate_type { RECTANGULAR = 1, POLAR };
      int RECTANGULAR; // 编译错误！命名冲突
      // ...
  }
  ```

## 3.4 底层函数的修改（适配标志位）

结构体存储格式改变后，底层的存取函数必须对应修改，但**只要保证函数接口（函数名、参数和返回值）不变，上层运算函数就完全不受影响**，这就是数据抽象的优势。

```c
struct complex_struct make_from_real_img(double x, double y)
{
    struct complex_struct z;
    z.t = RECTANGULAR; // 打上直角坐标的标志
    z.a = x;
    z.b = y;
    return z;
}

struct complex_struct make_from_mag_ang(double r, double A)
{
    struct complex_struct z;
    z.t = POLAR; // 打上极坐标的标志
    z.a = r;
    z.b = A;
    return z;
}
```

## 3.5 习题解答

### 习题 1：实现 `real_part`、`img_part`、`magnitude`、`angle` 函数

**要求**：根据标志位 `t` 判断当前结构体存储的坐标类型，并计算返回对应的值。

**解答代码**：

```c
#include <math.h>

// 获取实部
double real_part(struct complex_struct z)
{
    if (z.t == RECTANGULAR)
        return z.a;
    else
        return z.a * cos(z.b); // 极坐标转直角坐标：x = r * cos(A)
}

// 获取虚部
double img_part(struct complex_struct z)
{
    if (z.t == RECTANGULAR)
        return z.b;
    else
        return z.a * sin(z.b); // 极坐标转直角坐标：y = r * sin(A)
}

// 获取模
double magnitude(struct complex_struct z)
{
    if (z.t == POLAR)
        return z.a;
    else
        return sqrt(z.a * z.a + z.b * z.b); // 直角坐标转极坐标求模
}

// 获取幅角
double angle(struct complex_struct z)
{
    if (z.t == POLAR)
        return z.b;
    else
        return atan2(z.b, z.a); // 直角坐标转极坐标求幅角
}
```

### 习题 2：分析指定程序的编译运行结果

**代码片段**：

```c
#include <stdio.h>
enum coordinate_type { RECTANGULAR = 1, POLAR };
int main(void)
{
    int RECTANGULAR;
    printf("%d %d\n", RECTANGULAR, POLAR);
    return 0;
}
```

**结果与解释**：

- **运行结果**：**编译报错（Compilation Error）**，无法生成可执行文件。
- **错误原因**：在C语言中，**枚举常量（如 `RECTANGULAR`）和普通变量名属于同一个命名空间**。
代码中先定义了枚举成员 `RECTANGULAR`，随后在 `main` 函数内部又定义了同名的整型变量，两者命名冲突，编译器无法区分，报出重复定义错误。
- **修改方法**：将 `int RECTANGULAR;` 改为其他不冲突的变量名（例如 `int r;`）。
