# 1. 数组的基本概念

数组（Array）是一种复合数据类型，由一系列**相同类型的元素**（Element）顺序组成。例如定义一个包含4个 `int` 型元素的数组 `count`：

```c
int count[4];
```

## 1.1 数组的内存布局与嵌套

- **存储空间连续**：和结构体成员类似，数组中各个元素的存储空间是连续相邻排列的。
- **互相嵌套规则**：
  - 数组的元素可以是复合数据类型，例如定义一个由4个复数结构体元素组成的数组：
  ```c
  struct complex_struct {
      double x, y;
  } a[4];
  ```
  - 结构体中也可以包含数组成员：
  ```c
  struct {
      double x, y;
      int count[4];
  } s;
  ```

## 1.2 数组的访问与下标

- **长度指定**：定义数组时，长度必须用**整数常量表达式**指定。
- **下标（Index）**：通过下标访问数组元素，下标**从 0 开始计数**。上述4个元素的数组，分别通过 `count[0]`、`count[1]`、`count[2]`、`count[3]` 访问。
- **地址计算规则**：`count[i]` 表示从数组首地址开始，跳过 `i * sizeof(元素类型)` 个字节后的存储单元。
- **左值特性**：数组下标表达式不仅可以读取值，也可以代表存储单元本身（作为左值）：
```c
count[0] = 7;
count[1] = count[0] * 2;
++count[2];  // 等价于 ++(count[2])
```

> 
> ?? **优先级注意**：后缀运算符（如下标 `[]`、函数调用 `()` 等）优先级最高。`++count[2]` 会先执行 `count[2]` 取元素，再对该元素执行前缀 `++`。
- **下标表达式**：下标可以是任意表达式，但表达式的结果**必须是整型**。
```c
int i = 1;
count[i] = count[i+1];
```

## 1.3 数组的初始化

数组的初始化规则与结构体类似，未显式赋值的元素自动初始化为 0。

```c
int count[4] = { 3, 2, }; // count[0]=3, count[1]=2, count[2]=0, count[3]=0
```

如果定义数组的同时进行初始化，**可以省略长度**，编译器会根据初始化列表的元素个数自动确定数组长度：

```c
int count[] = { 3, 2, 1, }; // 数组长度自动为 3
```

**C99 新特性：指定下标初始化**：

```c
int count[4] = { [2] = 3 }; // 仅将下标为2的元素赋值为3，其余元素默认为0
```

## 1.4 常见陷阱：数组越界与遍历

- **越界访问问题**：C 语言编译器**不检查**数组下标越界，例如 `count[-1]` 或 `count[100]` 这类写法可以编译通过，但运行时可能直接触发段错误崩溃，也可能引发隐蔽的逻辑Bug，调试成本极高。编写代码时必须自行检查边界合法性。
- **数组遍历（Traversal）**：通过 `for` 循环依次访问数组元素，需特别注意循环的终止条件。
```c
#include <stdio.h>
int main(void) {
    int count[4] = { 3, 2, }, i;
    for (i = 0; i < 4; i++) // 注意：是 i < 4，不能写成 i <= 4，否则会访问越界
        printf("count[%d]=%d\n", i, count[i]);
    return 0;
}
```

## 1.5 数组的赋值与传参限制（重点）

- **数组之间不能直接赋值或初始化**：

```c
int a[5] = { 4, 3, 2, 1 };
int b[5] = a; // 错误：不能用一个数组初始化另一个数组
a = b;        // 错误：不能用数组给另一个数组整体赋值
```
- **不能直接作为函数参数或返回值传递**：如果写出 `void foo(int a[5])`，编译器不会报错，但这**并不代表**传递的是完整数组类型。
  - **核心规则**：数组类型作为右值使用时，**会自动转换为指向数组首元素的指针**。
  - 因此 `foo(array);` 实际上传递的是一个指针类型的参数。
  - 这也解释了 `a = b` 报错的原因：`b` 作为右值时自动退化为指针，而 `a` 仍然是数组类型，两边类型不兼容，报错 `error: incompatible types in assignment`。

## 1.6 课后习题实践

**题目**：编写程序，定义两个类型和长度都相同的数组，将其中一个数组的所有元素拷贝到另一个数组中。既然数组不能直接整体赋值，思考实现方式。

**实现思路**：使用 `for` 循环遍历，逐个元素进行赋值。

```c
#include <stdio.h>
int main(void) {
    int a[5] = {1, 2, 3, 4, 5};
    int b[5] = {0}; // 初始化为0
    int i;

    printf("拷贝前 b: ");
    for (i = 0; i < 5; i++) printf("%d ", b[i]);
    printf("\n");

    // 逐个元素拷贝
    for (i = 0; i < 5; i++) {
        b[i] = a[i];
    }

    printf("拷贝后 b: ");
    for (i = 0; i < 5; i++) printf("%d ", b[i]);
    printf("\n");

    return 0;
}
```

# 2. 数组应用实例：统计随机数

本节通过完整实例介绍数组的基础使用模式。问题场景：先生成一列 0~9 的随机数存入数组，再统计每个数字出现的次数，验证随机数的分布均匀性。

## 2.1 伪随机数（Pseudorandom）与 `rand` 函数

计算机的每一条指令执行结果都是确定的，没有指令能生成真正的随机数。
调用C标准库得到的随机数本质是**伪随机数**：通过数学公式计算出的确定数值，只是外观呈现随机性，且统计意义上接近均匀分布。

C标准库中生成伪随机数的核心函数是 **`rand`**：

- 头文件：使用需包含 `<stdlib.h>`
- 返回值：介于 `0` 和 `RAND_MAX` 之间、近似均匀分布的整数。`RAND_MAX` 是头文件中定义的大值常量。
- **限定范围**：通常需要将随机数限定在指定区间（如 0~9），可通过 `%` 取模运算处理：
```c
int x = rand() % 10; // 生成 0 到 9 的随机整数
```

### 示例：生成并打印 20 个随机数

```c
#include <stdio.h>
#include <stdlib.h>
#define N 20
int a[N];

void gen_random(int upper_bound)
{
    int i;
    for (i = 0; i < N; i++)
        a[i] = rand() % upper_bound;
}

void print_random()
{
    int i;
    for (i = 0; i < N; i++)
        printf("%d ", a[i]);
    printf("\n");
}

int main(void)
{
    gen_random(10);
    print_random();
    return 0;
}
```

## 2.2 深入理解 `#define` 与预处理阶段

上面的代码中使用 `#define N 20` 定义常量。编译器的工作分为两个核心阶段：

1. **预处理（Preprocess）阶段**：处理所有以 `#` 开头的指令行
2. **编译阶段**：对预处理后的代码进行编译

通过 `gcc -E main.c`（或 `cpp main.c`）可以查看预处理后的完整代码。预处理阶段主要完成两件事：

- **展开头文件**：将 `#include <stdio.h>` 等头文件的内容完整复制到代码中
- **宏替换**：将 `#define` 定义的标识符 `N` 全局替换为其定义值 `20`

**`#define` 与 `const` 的核心区别**：

- `#define` 在**预处理阶段**处理，不仅可以定义常量，还可以定义复杂的宏
- `const` 在**编译阶段**处理，是修饰变量的类型限定符

> 
> ?? **注意**：虽然 `include` 和 `define` 在预处理指令中有特殊含义，但它们**并不是 C 语言的关键字**。只有在行首带 `#` 时，预处理器才会将其当作指令；出现在其他位置时，它们只是普通标识符。

## 2.3 避免硬编码（Hard coding）

如果定义数组长度时不使用宏，直接写死数值：

```c
int a[20]; // 并且每个循环中都直接写 20
```

这种写法称为**硬编码**。如果后续需要将数组长度从 20 改成 10000，就需要在整个代码中逐个排查哪些 `20` 是数组长度、哪些是其他含义的数值，极易出错。

使用 `#define N 10000` 相当于提取了“公因子”，从根源避免了硬编码。这本质上也是一种**抽象**过程，避免局部改动波及大范围代码。这一思想在嵌入式开发中极其重要（如定义寄存器地址、硬件缓冲区大小）。

## 2.4 统计随机数的分布

验证随机数的均匀性需要足够的样本量，20个样本说明不了问题。我们生成 100000 个随机数，统计 0~9 每个数字出现的次数。

### 示例：统计分布完整程序

```c
#include <stdio.h>
#include <stdlib.h>
#define N 100000 // 样本量设为 10 万
int a[N];

void gen_random(int upper_bound)
{
    int i;
    for (i = 0; i < N; i++)
        a[i] = rand() % upper_bound;
}

// 统计指定数字在数组中出现的次数
int howmany(int value)
{
    int count = 0, i;
    for (i = 0; i < N; i++)
        if (a[i] == value)
            ++count;
    return count;
}

int main(void)
{
    int i;
    gen_random(10);
    printf("value\thow many\n");
    for (i = 0; i < 10; i++)
        printf("%d\t%d\n", i, howmany(i));
    return 0;
}
```

**运行结果说明**：0~9 每个数字出现的次数都在 10000 次左右，可见 `rand` 生成的伪随机数分布比较均匀。

## 2.5 课后习题解答

**题目**：用 `rand` 函数生成 `[10, 20]` 之间的随机整数，表达式应该怎么写？

**解答思路与公式**：

1. 首先 `rand() % 11` 可以生成 0 到 10 之间的整数（取模结果不包含除数本身）
2. 整体加 10，将区间偏移到 10 到 20

```c
int x = rand() % 11 + 10; 
```

# 3. 数组应用实例：直方图

承接上一节的随机数统计场景：统计一列 0~9 随机数中每个数字的出现次数，这类统计结果称为**直方图（Histogram）**。实际开发中，我们不仅需要打印统计结果，更需要将结果保存下来用于后续处理。

## 3.1 统计思路的演进：从低效到高效

### 3.1.1 思路一：多次遍历（低效）

最直观的思路是：为了统计 0~9 每个数字的出现次数，将原数组从头到尾遍历十遍，每一遍只统计一种数字的出现次数。

```c
int main(void)
{
    int i, histogram[10];
    gen_random(10);
    for (i = 0; i < 10; i++)
        histogram[i] = howmany(i); // 每次调用howmany都会完整遍历一次原数组
    // 打印结果...
}
```

**缺点**：若原数组有 10 万个元素，程序需要完整遍历 10 次，时间复杂度为 O(n×m)，效率极低。

### 3.1.2 思路二：单次遍历（Single Pass，高效）

与其让代码主动“查找”数字，不如让数字自己“对号入座”。我们可以把 `histogram` 数组的每个元素当作**累加器**，仅通过一次遍历完成全部统计。

```c
int main(void)
{
    int i, histogram[10] = {0}; // 必须初始化为0！局部数组未初始化时值不确定
    gen_random(10);
    for (i = 0; i < N; i++)
        histogram[a[i]]++; // 核心逻辑：用元素值直接作为下标
    // 打印结果...
}
```

**原理解析**：
每次循环中，`a[i]` 是当前生成的随机数，而这个随机数同时也是 `histogram` 数组的下标。随机数每出现一次，就将 `histogram` 对应位置的计数加 1。

这种「用数值本身作为下标直接寻址」的思想，在频率统计、状态机、查表法等场景中极其常用，本质是用空间换时间，避免循环查找。

## 3.2 真正的随机数：随机数种子（Seed）

如果多次运行上一节的程序，会发现每次生成的随机数序列完全相同。这是因为 `rand()` 生成伪随机数的底层是确定的数学公式，计算的起点是一个固定**初值**，只要初值相同，后续整个数列就完全一致。

在 C 标准库中，这个初值称为 **Seed（种子）**。我们可以通过 `srand` 函数手动指定种子：

```c
#include <time.h> // time 函数需要的头文件

int main(void)
{
    // time(NULL) 获取当前系统时间距1970年1月1日00:00:00的秒数（Unix时间戳）
    // 每次运行程序的时间不同，种子就不同，生成的随机数序列也不同
    srand(time(NULL)); 
    
    gen_random(10);
    // ...后续逻辑
}
```

## 3.3 课后习题思路提示

### 习题 1：可视化形式打印直方图

**题目**：用 `*` 号直观打印直方图（例如 `***` 表示出现 3 次）。

**横向打印思路（易实现）**：
使用双层循环。外层循环遍历 0~9 的数字，内层循环根据该数字的统计次数，循环打印 `*` 号。

```c
// 核心逻辑伪代码
for (i = 0; i < 10; i++) {
    printf("%d: ", i);
    for (j = 0; j < histogram[i]; j++) {
        printf("*");
    }
    printf("\n");
}
```

**纵向打印思路（进阶）**：
需要先行后列思考：先找到出现次数的最大值作为直方图的总高度，外层循环从最高层向下逐层遍历，内层循环遍历 0~9 的数字，若该数字的次数大于等于当前高度则打印 `*`，否则打印空格。

### 习题 2：全排列（递归进阶）

**题目**：打印数组的全排列（例如 `[1, 2, 3]` 的全排列有 6 种）。

**思路提示**：
这是经典的递归算法题，也是校招面试的高频考点。核心思路是：依次将第 1 个元素和后面每个元素交换，固定第一个位置，然后对剩余的子数组递归做全排列。递归的**Base Case（终止条件）**是：当待排列的起点下标等于数组长度时，说明所有位置都已固定，打印当前数组。

> 
> ? 提示：如果你目前对递归的掌握还不熟练，这道题可以先跳过，等学完指针和函数进阶内容后再回来练习。

# 4. 字符串
字符串本质上是字符数组，但在C语言中有特殊的约定：每一个合法字符串的末尾，都有一个 ASCII 码为 0 的空字符 `'\0'` 作为结束标志。这种字符串也称为**以零结尾的字符串（Null-terminated String）**。

例如字符串 `"Hello, world.\n"` 在内存中的存储结构：  
`'H'` | `'e'` | `'l'` | `'l'` | `'o'` | `','` | `' '` | `'w'` | `'o'` | `'r'` | `'l'` | `'d'` | `'.'` | `'\n'` | `'\0'`

## 4.1 字符串字面值（String Literal）的特性
直接写在代码中的双引号文本称为**字符串字面值**，它有三个核心特性：

1. **支持下标访问**
   字符串字面值可以像普通数组一样通过下标读取字符：
   ```c
   char c = "Hello, world.\n"[0]; // c 的值为 'H'
   ```

2. **只读属性（极其重要）**
   字符串字面值存储在只读内存区域，绝对不能通过下标修改其内容。以下代码会触发编译错误或运行时段错误：
   ```c
   "Hello, world.\n"[0] = 'A'; // 错误！试图修改只读内存
   ```

3. **自动退化为指针**
   字符串字面值作为右值使用时，会自动转换为指向首字符的指针。这也是 `printf("hello world")` 可以正常工作的原因：传递给 `printf` 的本质是指向字符 `'h'` 的指针。

## 4.2 字符数组的初始化
如果需要存储并修改文本，必须将内容存放在**字符数组**中。可以用字符串字面值来初始化字符数组：
```c
char str[10] = "Hello";
```
这行代码完全等价于：
```c
char str[10] = {'H', 'e', 'l', 'l', 'o', '\0'};
```

> ? 说明：数组中未显式初始化的后 4 个元素，会自动初始化为 0（即 `'\0'`）。
> 虽然字符串字面值 `"Hello"` 本身是只读的，但用它初始化得到的数组 `str` 是可读可写的。

## 4.3 长度陷阱（极易踩坑）
如果字符数组的长度小于字符串字面值的总长度（含结尾 `'\0'`），例如：
```c
char str[10] = "Hello, world.\n"; // 字面值总长度 15，无法放入长度为 10 的数组
```
此时编译器会报错或给出警告，数组只会保留前 10 个字符，**不包含结尾的 Null 字符**。

### 更隐蔽的陷阱（C99 特殊规定）
如果数组长度刚好比字面值的总长度（含 `'\0'`）少 1，例如：
```c
char str[14] = "Hello, world.\n"; // 刚好放下 14 个可见字符，放不下结尾 '\0'
```
此时数组 `str` **不包含 Null 结束字符，且编译器不会给出任何警告**（C99 标准的特殊规定），会埋下严重的越界隐患。

### 最佳实践
如果用字符串字面值初始化字符数组，**最稳妥的方式是不指定数组长度**，让编译器自动计算总长度并补全结尾 `'\0'`：
```c
char str[] = "Hello, world.\n"; // 编译器自动计算长度为 15，并自动补上 '\0'
```

## 4.4 `%s` 格式化与越界风险
在 `printf` 中，可以使用 **`%s`** 作为字符串的占位符：
```c
char str[] = "Hello";
printf("string: %s\n", str);
```

### printf 处理 %s 的工作原理
遇到 `%s` 时，`printf` 会从传入的起始地址开始向后逐个打印字符，**直到遇到 Null 字符（`'\0'`）为止**。Null 字符本身是不可打印字符，不会输出到终端。

?? **危险警告**：
如果字符数组中**没有 Null 结束字符**（比如上述的长度陷阱，或者数组未正确初始化），`printf` 会持续向后访问内存，造成**数组越界**。
后果具有不确定性：可能打印出一堆乱码，可能表面运行正常，也可能直接触发段错误（Segmentation fault）导致程序崩溃。

---

### ? 嵌入式视角延伸
在 STM32 的串口通信（UART）中，我们经常需要发送字符串，比如 `printf("System Boot Success!\r\n");`。
如果遗漏 `\r\n`（回车换行），或者字符串处理函数（如 `strcpy`、`strlen`）遇到没有 `\0` 结尾的字符数组，轻则串口助手持续输出乱码，重则直接触发 HardFault 硬件异常死机。因此，**「字符串必须以 `\0` 结尾」** 是嵌入式 C 开发中必须牢记的铁律。

# 5. 多维数组

和结构体可以嵌套类似，数组也可以嵌套。一个数组的元素本身可以是另一个数组，这样就构成了**多维数组（Multi-dimensional Array）**。

## 5.1 概念模型与物理模型

以二维数组为例：

```c
int a[3][2] = { {1, 2}, {3, 4}, {5, 0} };
```

- **概念模型**：数组 `a` 共有 3 个元素 `a[0]`、`a[1]`、`a[2]`，每个元素本身又是一个包含 2 个 `int` 的数组。从逻辑上看，它对应一张 3 行 2 列的表格。
- **物理模型**：在计算机内存中，这 6 个元素依然是**连续存储**的，相当于把概念模型的表格按行依次拼接成一串。C语言的这种存储方式称为 **Row-major（行优先）**；部分编程语言（如 FORTRAN）采用 Column-major（列优先）存储。

## 5.2 初始化规则与指定初始化（C99）

多维数组可以像嵌套结构体一样，使用嵌套大括号进行初始化：

```c
int a[][2] = { {1, 2}, {3, 4}, {5, } };
```

> 
> ?? **重要规则**：定义多维数组时，**只有第一维的长度可以由编译器自动计算，其余各维都必须明确指定长度**。编译器需要根据后续维度的大小计算内存偏移量。

**C99 特性：指定下标初始化**
可以精确指定具体下标的元素进行初始化，未指定的元素自动为 0：

```c
int a[3][2] = { [0][1] = 9, [2][1] = 8 }; 
```

结构体与数组嵌套时，也可以使用该特性：

```c
struct complex_struct { double x, y; } a[4] = { [0].x = 8.0 };
struct { double x, y; int count[4]; } s = { .count[2] = 9 };
```

## 5.3 多维字符数组与“数据驱动编程”

当字符串字面值嵌套在数组中时，就构成了多维字符数组，典型应用是查表式编程。

**示例：打印星期几**

```c
void print_day(int day)
{
    char days[8][10] = { "", "Monday", "Tuesday",
                         "Wednesday", "Thursday", "Friday",
                         "Saturday", "Sunday" };
    if (day < 1 || day > 7)
        printf("Illegal day number!\n");
    printf("%s\n", days[day]);
}
```

> 
> ? **为什么定义为 `[8][10]`？**
> 第一维设为 8，是为了让下标 1~7 刚好对应星期一到星期日，`days[0]` 空置不用。第二维设为 10，是因为最长的字符串 `"Wednesday"` 有 9 个字符，加上末尾的 `\0` 刚好占用 10 个字节。

### 核心思想：数据驱动编程（Data-driven Programming）

这段代码用数组下标访问**替代了一长串 `switch-case` 分支**。`switch-case` 容易因漏写 `break` 产生 Bug；而数组查表法以数据为核心，代码更简洁，维护成本极低。

> 
> 《人月神话》中提到：“Show me your flowcharts and conceal your tables, and I shall continue to be mystified. Show me your tables, and I won't usually need your flowcharts; they'll be obvious.”
> （展示你的流程图、隐藏你的表格，我仍会感到困惑；展示你的表格、隐藏你的流程图，通常就不需要流程图了，逻辑会一目了然。）

## 5.4 实战案例：剪刀石头布

程序内部用 `0, 1, 2` 分别表示剪刀、石头、布。

**核心代码逻辑**：

```c
char gesture[3][10] = { "scissor", "stone", "cloth" };
// ... 省略部分代码
printf("Your gesture: %s\tComputer's gesture: %s\n", 
        gesture[man], gesture[computer]);

// 胜负判定公式
result = (man - computer + 4) % 3 - 1; 
if (result > 0)
    printf("You win!\n");
else if (result == 0)
    printf("Draw!\n");
else
    printf("You lose!\n");
```

### 胜负判定公式原理解析

胜负规则：石头(1)赢剪刀(0)、布(2)赢石头(1)、剪刀(0)赢布(2)。代入公式 `(man - computer + 4) % 3 - 1` 验证：

- **平局**：`man == computer`，差值为 0
代入：`(0 + 4) % 3 - 1 = 1 - 1 = 0`，结果等于 0。
- **玩家赢**：例如 man=石头(1)，computer=剪刀(0)，差值为 1
代入：`(1 + 4) % 3 - 1 = 5 % 3 - 1 = 2 - 1 = 1`，结果大于 0。
再验证 man=布(2)、computer=石头(1)，差值为 1，结果一致。
- **玩家输**：例如 man=剪刀(0)，computer=石头(1)，差值为 -1
代入：`(-1 + 4) % 3 - 1 = 3 % 3 - 1 = 0 - 1 = -1`，结果小于 0。

**原理总结**：
C语言中 `%` 取模的结果符号与被除数一致。公式通过加 4 将所有差值偏移到正数区间再取模，最终通过减 1 完成映射：获胜场景统一映射为 `1`，落败场景统一映射为 `-1`，平局映射为 `0`，用一个数学公式替代了多分支判断。

## 5.5 补充知识：scanf 函数

`scanf` 是C标准库中用于处理用户输入的函数，使用需引入 `<stdio.h>`。

```c
int ret = scanf("%d", &man);
```

- **格式控制符**：`%d` 表示读取一个整数。
- **取地址符 `&`**：`&man` 表示获取变量 `man` 的内存地址。`scanf` 需要知道数据的存储位置，因此必须传入地址。
- **返回值 `ret`**：`scanf` 返回成功读取的数据个数。如果用户输入非法字符（如字母），`ret` 会返回 0。通常通过判断 `ret != 1` 来处理异常输入。
- **与 printf 的区别**：`printf("%d", man)` 不需要传地址，只需要变量的值即可；但 `scanf` 读取字符串（`%s`）时，第二个参数直接传数组名即可（数组名本身就是首地址，无需加 `&`）。
