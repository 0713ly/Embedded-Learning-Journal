# 1. 位运算

整数在计算机中用二进制的位来表示。C 语言提供了一些运算符可以直接操作整数中的位，称为**位运算**。这些运算符的操作数**必须是整型**。
在实际开发（尤其是嵌入式开发）中，很多信息（如硬件寄存器、标志位、权限控制）都是利用整数中的某几个位来存储的，必须借助位运算来访问。

## 1.1 按位与、或、异或、取反运算

C 语言提供了以下位运算符：
*   **按位与（Bitwise AND）**：`&`
*   **按位或（Bitwise OR）**：`|`
*   **按位异或（Bitwise XOR）**：`^`
*   **按位取反（Bitwise NOT）**：`~`

**运算规则（真值表）**：
*   `&`：两个位都是 1 时结果才为 1，否则为 0。
*   `|`：两个位只要有一个为 1 结果就为 1，都为 0 时才为 0。
*   `^`：两个位相同为 0，不同为 1。
*   `~`：单目运算符，把 0 变 1，1 变 0。

> ?? **重点注意（整型提升）**：
> `&`、`|`、`^`、`~` 运算符在计算前，都会进行 **Integer Promotion（整型提升）**。在 C 语言中，**实际上不存在 8 位整数的位运算**，操作数在做位运算前至少被提升为 `int` 型。
> 例如：`unsigned char c = 0xfc; unsigned int i = ~c;`
> 计算时 `c` 先提升为 `int` 的 `0x000000fc`，取反后变成 `0xffffff03`，最后赋给 `i`。如果误以为是 8 位取反（变成 `0x03`），就会出错。

## 1.2 移位运算

移位运算符包括**左移 `<<`** 和**右移 `>>`**。操作数必须是整型。移位位数必须小于左操作数的总位数，否则结果是 **Undefined（未定义）**。

### 1. 左移运算 (`<<`)
将一个整数的各二进制位全部左移若干位，**高位移出丢弃，低位补 0**。
*   **数学意义**：在一定取值范围内（不改变符号位），**左移 1 位相当于乘以 2**。
*   **优化**：计算机做移位比做乘法快得多，编译器会将源码中的 `x * 8` 优化为 `x << 3`。

### 2. 右移运算 (`>>`)
各二进制位右移若干位，**低位移出丢弃，高位补什么取决于操作数的符号性**。
*   **无符号数**：高位补 0（逻辑右移）。在一定取值范围内，**右移 1 位相当于除以 2**（截断小数部分）。
*   **有符号数（较复杂）**：
    *   如果是正数，高位补 0。
    *   如果是负数，高位补 1 还是 0 属于 **Implementation-defined（实现定义）**。在 x86/gcc 平台上，高位补 1（算术右移），以保持“右移 1 位相当于除以 2”的特性。
*   **建议**：由于有符号数右移和类型转换的复杂性，**尽量只对无符号数做位运算**，以减少出错。

**习题提示**：
`printf("%x\n", 0xcfffffff3>>2);` 与 `printf("%x\n", i>>2);` （其中 `int i = 0xcfffffff3;`）
第一个常量是无符号数（补0），第二个是负数（补1），因此结果不同。

## 1.3 掩码（Mask）

如果要对整数的某几位进行操作，可以用**掩码（Mask）**来表示这些位。
假设掩码 `mask = 0x0000ff00`（对应第 8~15 位）：

1.  **取出特定位**：
    ```c
    b = (a & mask) >> 8; // 先与掩码按位与，将其他位清零，再右移 8 位得到数值
    ```
2.  **将特定位清零**：
    ```c
    b = a & ~mask; // 掩码取反（目标位变0，其他位变1），再按位与
    ```
3.  **将特定位置 1**：
    ```c
    b = a | mask; // 直接按位或
    ```

## 1.4 异或运算的一些特性

异或 `^` 是位运算中最神奇的一个，经常用于底层算法优化和数据校验。

1.  **自己异或自己等于 0**：`a ^ a = 0`。编译器常利用此特性用 `xor eax, eax` 指令快速清空寄存器（比 `mov eax, 0` 快）。
2.  **翻转特定位**：`a ^ 0 = a`，`a ^ 1 = ~a`。利用掩码按位异或，可以实现对特定位置的翻转。
3.  **奇偶校验（Parity Check）**：连续异或的结果如果是 1，表示这组数中 1 的个数为奇数；为 0 则为偶数。常用于通信数据的校验。
4.  **不用中间变量交换两个数**：
    ```c
    a = a ^ b;
    b = b ^ a; // 相当于 b ^ (a ^ b) = a
    a = a ^ b; // 相当于 (a ^ b) ^ a = b
    ```
    *注意：这个方法不能把同一个变量自己跟自己交换，因为 `a ^ a = 0`，会导致值丢失。*
